# Excel Coaching Center Landing Page 🎓

A modern, responsive, and pixel-perfect coaching center landing web page designed for premier academic institutes offering coaching for JEE, NEET, Foundation, and Board Exams.

![Excel Coaching Center Preview](assets/images/hero-student.jpg)

## ✨ Features

- **Hero Section**: High-impact headline, CTA buttons, quick stats badges, and custom curved imagery.
- **About Us**: Institute overview with key pillar highlights (Experienced Faculty, Personalized Attention, Regular Assessments, Smart Learning).
- **Courses We Offer**: Color-coded program cards for Foundation, Competitive Exams (JEE/NEET), School Coaching (CBSE/ICSE), and Crash Courses.
- **Moments at Excel (Gallery)**: Interactive photo gallery with lightbox modal preview.
- **Our Results & Track Record**: Animated stats counter on scroll showing selection numbers and success rates.
- **Student Testimonials**: Card testimonials on a deep navy background with carousel indicators.
- **Contact & Enquiry Form**: Complete enquiry submission form with field validation and toast notifications.
- **Interactive Map**: Google Maps location pin card.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop screens.

## 🛠️ Built With

- **HTML5** & Semantic Elements
- **Vanilla CSS3** (Custom Properties, Flexbox, CSS Grid)
- **Vanilla JavaScript** (ES6+, IntersectionObserver, DOM Manipulation)
- **Google Fonts** (Plus Jakarta Sans & Inter)
- **Font Awesome 6** Icons

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or run a local web server:

```bash
# Python 3
python -m http.server 3000

# or Node / npx
npx serve .
```

Open `http://localhost:3000` in your browser.
